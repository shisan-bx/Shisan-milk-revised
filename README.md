# 传讯 💌

> 🔗 **在线体验：<https://shisan-m.netlify.app/>**

一个纯前端的「与梦角聊天」网页应用：原生 HTML / CSS / JavaScript，无需后端、无需构建，打开即用。数据全部保存在本地浏览器（IndexedDB），支持一键备份与恢复。

## ✨ 功能一览

### 💬 聊天互动
- **智能回复**：基于自定义字卡回复库，支持分组管理、批量导入导出、命中/随机回复
- **消息操作**：点击或长按消息即可 ⭐收藏、↩️引用回复、📝添加注释、🗑️删除
- **收藏分组**：同一次收藏的消息自动归入一组，收藏夹按组浏览，支持整组取消
- **拍一拍**：快捷动作面板内直接添加 / 删除动作，另有一次性自定义动作
- **表情 & 图片**：我的表情库 / 对方表情库，支持上传管理
- **批量发送**：一次编辑多条消息依次发出
- **主动发消息**：定时发送 / 随机间隔发送（两种模式互斥）
- **群聊模式**：可配置多个群组成员，聊天与朋友圈行为按成员随机分配

### 📸 朋友圈
- 梦角发布图文动态，可点赞、评论、回复评论
- **自动发朋友圈**：开启后随机时间自动发布，条数无上限（至少三天一条）
- **手动催更**：一键让梦角立刻发一条
- 文案库与字卡库联动，发帖内容可从所选字卡分组中随机抽取
- 群组模式下点赞、评论、发帖均由随机群成员身份执行

### 📞 视频通话 & 🎵 音乐
- 模拟视频通话：来电 / 呼出铃声、后台来电提醒、开关与音量均可配置
- 悬浮音乐播放器：本地歌单 + 外链歌曲、懒加载省流量、可拖拽、可随时关闭
- 网站保活音频，可自定义链接

### 🎨 个性化
- 日 / 夜主题、多套配色、自定义气泡 CSS、聊天背景、字体
- 自定义双方昵称与头像
- 纪念日纪念、每日公告、信封、抉择小游戏等小功能

### 🛡️ 数据安全
- 所有数据仅存于本地浏览器（localforage / IndexedDB），不上传任何服务器
- 支持选择性导出 / 导入（聊天记录、字卡、设置、主题、纪念日等）
- 支持全量备份与恢复，新旧版本数据自动迁移


## 📁 项目结构

```
├── index.html          # 主页面
├── server.js           # 本地静态服务器（可选）
├── css/
│   └── styles.css      # 全部样式
├── js/
│   ├── config.js       # 常量与默认配置
│   ├── state.js        # 全局状态
│   ├── core.js         # 数据加载 / 保存 / 渲染 / 备份
│   ├── listeners.js    # 交互事件
│   ├── games.js        # 表情拍一面板、统计与收藏渲染
│   ├── utils.js        # 自定义弹窗、工具函数
│   ├── onboarding.js   # 新手引导
│   ├── data.js / features.js
│   └── features/
│       ├── moments.js        # 朋友圈
│       ├── call.js           # 视频通话
│       ├── reply-library.js  # 字卡回复库
│       ├── group-chat.js     # 群组模式
│       ├── mood.js           # 批量收藏等
│       ├── envelope.js       # 信封
│       └── theme-editor.js   # 主题编辑
├── music/              # 本地音乐文件
├── sounds/             # 铃声等音效
└── images/             # 图片资源
```
